Search dinosaurs by clade, diet, and locomotion

GET
/search

Retrieves dinosaurs matching the provided query parameters. Matching is case-insensitive. Multiple clades may be provided as a comma-separated list.

Parameters

Section titled “ Parameters ”

Query Parameters

Section titled “Query Parameters ”
clade
Array<string>

One or more clades. Can be provided as a comma-separated list (e.g. Dinosauria,Ornithischia).

Example
diet
string
Allowed values: carnivore herbivore omnivore piscivore
Example
locomotion
string
Allowed values: biped facultative biped gliding quadruped swimming
