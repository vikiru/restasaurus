## Quick Start

```javascript
// Example API call
const response = await fetch('https://api.restasaurus.com/endpoint', {
  headers: {
    'Authorization': 'Bearer YOUR_API_KEY',
    'Content-Type': 'application/json'
  }
});
const data = await response.json();
```
